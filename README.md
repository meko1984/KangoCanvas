# KangoCanvas

看護学生向けの、自由配置型看護関連図Webアプリです。

Web版（お試し版）: https://meko1984.github.io/KangoCanvas/

現在のバージョン: `v0.2.0`

## 現在の構成

- ブラウザ内だけに関連図を自動保存
- GitHub Pagesなどの静的ホスティングに対応
- 将来のレンタルサーバー移行を妨げない構成
- アカウント・クラウド同期・サーバー送信は未実装

## お試し版と製品版

- 公開版は、作業中の関連図1件をブラウザ内に保持するお試し版です
- 関連図を作る基本操作は両版で共通です
- お試し版は標準項目のみ使用でき、配置後の文章は編集できます
- 複数保存、自由入力、独自項目管理、バックアップ、専用PDF出力は製品版機能です
- 製品版の販売と解除方法は準備中です

詳しい区分は `docs/edition-spec-v0.2.0.md` を参照してください。

ローカル開発時は、画面右下の「開発確認」でお試し版と製品版を切り替えられます。公開ビルドでは切り替えは表示されず、お試し版として起動します。

## 開発

```sh
pnpm install
pnpm dev
```

本番用ファイルは `pnpm build` で `dist` に作成されます。

## 個人情報

氏名、患者ID、生年月日など、個人を特定できる情報は入力しないでください。
関連図データは利用者のブラウザ内に保存されますが、ブラウザデータの削除や
端末故障によって失われる可能性があります。お試し版の端末内データは一時的な
作業保持として扱ってください。製品版ではバックアップファイルを書き出せます。
