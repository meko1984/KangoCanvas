# KangoCanvas

看護学生向けの、自由配置型看護関連図Webアプリです。

Web版（全機能無料）: https://kangocanvas.mekomikudo.jp/

現在のバージョン: `v0.3.0`

## 現在の構成

- ブラウザ内だけに関連図を自動保存
- GitHub Pagesなどの静的ホスティングに対応
- 将来のレンタルサーバー移行を妨げない構成
- アカウント・クラウド同期・サーバー送信は未実装

## すべての機能が無料

- 標準項目376件からの配置、文章編集、矢印・囲み枠・整列
- 複数の関連図の保存・分類・複製
- 自由入力ボックスと独自項目管理
- 専用ファイルの書き出し・読み込み
- A4・A3のPDF出力とブラウザ標準印刷
- 購入・会員登録・機能解除は不要

旧お試し版で保存した図も、同じブラウザ・同じサイトの関連図一覧から開けます。
保存済みの図や独自項目を無料化によって削除することはありません。

ローカル開発版と公開版は同じ機能を提供します。
過去の区分は `docs/edition-spec-v0.2.0.md`、今回の変更は `docs/free-release-v0.3.0.md` に記録しています。

## 開発

```sh
pnpm install
pnpm dev
```

本番用ファイルは `pnpm build` で `dist` に作成されます。

## 個人情報

氏名、患者ID、生年月日など、個人を特定できる情報は入力しないでください。
関連図データは利用者のブラウザ内に保存されますが、ブラウザデータの削除や
端末故障によって失われる可能性があります。必要な図はバックアップファイルを
書き出してください。バックアップとPDFの共有前にも、内容を確認してください。
