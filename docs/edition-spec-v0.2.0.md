# KangoCanvas v0.2.0 エディション仕様

## 共通する作図機能

- 既存項目からのボックス作成
- 配置後の文章編集
- 分類色、移動、サイズ変更、複製、削除
- 矢印・線、囲み枠、整列、等間隔配置
- 文字サイズ・線幅、拡大縮小、画面移動
- 元に戻す・やり直す

## お試し版

- 作業できる関連図は1件
- 固定の作業領域をブラウザ内へ自動保存
- 「白紙に戻す」で現在の図を削除して作り直せる
- ブラウザのサイトデータ削除、端末変更、プライベートブラウズでは復元できない
- 登録済みの標準項目のみ利用可能
- 配置後のボックス文章は編集可能
- 自由入力ボックス、独自項目管理、複数保存、バックアップ、専用PDF出力は利用不可
- ブラウザ標準印刷は利用可能

## 製品版

- 複数の関連図、一覧、系統分類、複製、削除
- 自由入力ボックスと独自項目管理
- 専用ファイルの書き出し・読み込み
- PDF出力用フォーマットと印刷設定
- 将来、PNG出力、タグ、検索、並べ替えを追加予定

## モード運用

- 公開ビルドはお試し版として起動する
- 開発サーバーでは画面上の開発確認スイッチで両モードを切り替えられる
- お試し版と製品版は同じ作図部品と同じ関連図データ形式を使用する
- お試し版の固定作業領域と製品版の関連図一覧は別に保持し、切り替えても削除しない
- BOOTH購入後の製品版解除方式は、次の開発段階で追加する
