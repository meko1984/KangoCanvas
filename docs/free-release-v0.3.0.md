# v0.3.0 全機能無料化と公開前確認

## 変更内容

- 全機能を無料で提供。お試し版・製品版のモード、開発用切り替え、購入案内、機能制限を廃止。
- 複数の関連図、自由入力、独自項目管理、バックアップの書き出し・読み込み、PDF、ブラウザ印刷を共通提供。
- 旧お試し版の固定ID `kango-canvas-trial-workspace` を含め、同じサイトのIndexedDB内のすべての図を一覧に表示。保存データの削除・ID変換・タイトル変更は行わない。
- 新しい図は一覧の「新しい関連図」から作成する。旧お試し版の破壊的な「白紙に戻す」は廃止。
- 標準項目を126件から376件に拡充。詳細は `catalog-expansion-2026-09-11.md`。
- 保存領域の名前と形式、独自項目の設定は維持。異なるブラウザ・サイトのデータを自動的に統合する機能はない。

## 個人情報・秘密情報の確認

対象は今回GitHubへ送るソース、同梱サンプル、設定、ドキュメント、ロックファイルと、生成された公開用HTML・CSS・JavaScript。

- 実在の個人の氏名・住所・連絡先・患者IDが記入されたデータは見つからなかった。
- 同梱サンプルの人物属性と検査値は練習用で、「架空情報」と明記されている。元の参考画像、患者ファイル、画像・表計算・バックアップなどの添付ファイルは公開対象に含まれない。
- APIキー・アクセストークン・秘密鍵、個人用メールアドレス・電話番号、PCのユーザーディレクトリの記載は検出されなかった。
- 公開GitHubアカウント名、公開サイトのドメイン、一般公開された医療情報の参照URLは含まれる。今回のGitコミットのメールはGitHubのnoreplyアドレス。
- 図データはIndexedDB、独自項目はlocalStorageに保持。アプリのソースに図を外部へ送信するfetch・XMLHttpRequest・WebSocket・sendBeaconの処理やアクセス解析の追加はない。
- ブラウザに保存された利用者の図はGit管理対象でもビルド入力でもなく、今回の更新ではアップロードしない。
- 本確認は現在の公開対象の点検結果。過去のGit履歴すべて、利用者が入力する任意の内容、ホスティング事業者が通常処理するアクセス情報まで含む匿名性の保証ではない。

- 架空の同梱サンプルでバックアップ書き出しの完了表示を確認。
- 自由入力・独自項目管理の入口と、A4/A3のPDF設定画面へアクセスできることを確認。
